# Facebook Engagement – Telegram V1

Agent 18 verwendet Ticket-IDs wie `FB-A1B2C3D4`.

- `antwort FB-A1B2C3D4`: vorhandenen Antwortentwurf freigeben
- `ändern FB-A1B2C3D4 Neuer Text`: Text ersetzen und freigeben
- `ignorieren FB-A1B2C3D4`: schließen, nichts senden
- `info FB-A1B2C3D4`: Details anzeigen
- `memory FB-A1B2C3D4`: belegbare öffentliche Historie anzeigen

V1 setzt bei Freigabe ausschließlich `SEND_APPROVED`. Es existiert bewusst noch kein automatischer Facebook-Sendeweg.
