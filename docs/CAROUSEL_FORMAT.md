# Karussell-Format

Karussells bleiben Entwürfe, bis der Status ausdrücklich auf `FREIGEGEBEN` gesetzt wird. Instagram akzeptiert zwei bis zehn Bilder; bei mehr Bildern werden nur die ersten zehn verwendet.

## Instagram Karussell

```markdown
## Instagram Karussell
Status: FREIGEGEBEN
Text: Caption hier
Bilder:
- carousel-1234-1.jpg
- carousel-1234-2.jpg
- carousel-1234-3.jpg
```

## Facebook Karussell

```markdown
## Facebook Karussell
Status: FREIGEGEBEN
Text: Caption hier
Bilder:
- carousel-1234-1.jpg
- carousel-1234-2.jpg
- carousel-1234-3.jpg
```

Für einen Bildentwurf kann `Bilder: auto` verwendet werden. Der Mediengenerator erzeugt dann drei passende Hochkantbilder und ersetzt die Zeile durch die Dateinamen.
