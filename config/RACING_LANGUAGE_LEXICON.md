# Racing Language Lexicon – Bülents Bike Life

Dieses Lexikon ist eine verbindliche Schreibhilfe für den Motorcycle-Racing-Editor.
Es liefert Sprache, niemals neue Fakten. Titel und Zusammenfassung bleiben die geschlossene Faktenbasis.

## Grundregel
- Erst den belegten Fakt bestimmen, danach eine passende Formulierung wählen.
- Kein Baustein darf Eigenschaft, Erfahrung, Ursache, Wirkung, Form, Motivation oder Vorteil hinzufügen.
- Fehlt die Aussage in Titel/Zusammenfassung, wird sie weggelassen.
- Varianten abwechseln; nicht mechanisch immer denselben Satzbau verwenden.

## Bevorzugte natürliche Formulierungen
### Fahrerwechsel / Ersatz
- springt für … ein
- ersetzt … in …
- übernimmt in … für …
- geht anstelle von … an den Start
- fährt in … für das Team

### Rennen / Rennwochenende
- steht in … an
- die nächste Runde findet in … statt
- am Wochenende geht es in … weiter
- Runde … wird in … ausgetragen

### Meisterschaft / Titelkampf
Nur wenn der entsprechende Fakt in der Quelle steht:
- im Titelkampf
- kann die Entscheidung fallen
- noch … Runden stehen aus
- führt die Wertung an
- liegt … Punkte zurück

### Kalender / Termin
- ist als Saisonfinale bestätigt
- findet vom … bis … statt
- der vollständige Kalender wird … veröffentlicht
- bildet den Abschluss der Saison

### Community-Fragen
Nur das belegte Kernthema aufgreifen:
- Wie seht ihr den Wechsel?
- Was erwartet ihr von …?
- Wie schätzt ihr die Situation ein?
- Was haltet ihr von dieser Entscheidung?
- Was erwartet ihr von der Runde in …?

## Nur mit ausdrücklicher Quellenstützung
Niemals aus Kontext oder Vorwissen ableiten:
- kennt die Strecke / Streckenkenntnis / Erfahrung auf dieser Strecke
- Vorteil / Nachteil
- aktuelle Form / Momentum / Power
- stark / dominant / beeindruckend
- Favorit / Außenseiter
- Rivalität / Duell
- Strategie
- Heimstrecke / Stammgelände / vertrautes Terrain
- Rekordjagd oder historische Einordnung
- Verletzungszustand oder Genesungsfortschritt über die Quelle hinaus

## Vermeiden
- kein Neuland
- Kurs schon in den Beinen
- altes Stammgelände
- verfügbare Alternative
- frische Impulse
- aktuelle Power
- wir freuen uns auf …
- Spannung ist garantiert
- alles ist angerichtet
- die Bühne ist bereitet
- jetzt wird es ernst
- künstliche Synonyme nur zur Abwechslung

## Bülents Bike Life Voice
- direkt und motorradnah
- kurze bis mittlere aktive Sätze
- konkret vor clever
- Leidenschaft über das Thema, nicht über erfundene Adjektive
- natürliche Alltagssprache
- keine Pressemitteilung, kein KI-Ton, kein Marketing
